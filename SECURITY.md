# Security reports

Send reports to kodayorg@gmail.com. Do not include passwords, app-specific passwords, private keys, or full personal calendar files. Share the affected version, reproduction steps and a sanitized example. This mailbox uses Gmail (Google).

This project has no guaranteed response-time commitment. A fix and disclosure schedule is agreed after assessing a report. A valid code signature identifies a release and does not establish that the app has no vulnerabilities.
