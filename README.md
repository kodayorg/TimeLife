# TimeLife

Приложение-календарь для Windows 11 с возможностью синхронизации с iCloud. Имеет виджеты на рабочий стол с небольшой кастомизацией. Без рекламы и подписок. Использует шифрование Windows для защиты сохранённого пароля iCloud; локальный кеш событий не зашифрован.

## Установка

Установщик доступен в разделе [Releases](https://github.com/kodayorg/TimeLife/releases/tag/v0.1.17-preview). Текущая версия — неподписанная Preview: Windows может показать предупреждение SmartScreen или «Неизвестный издатель».

1. Скачайте установочный EXE TimeLife.
2. Запустите файл и следуйте инструкциям установщика.
3. Откройте TimeLife через меню «Пуск» или ярлык на рабочем столе.

## Синхронизация с iCloud

Используйте в TimeLife тот же аккаунт Apple, что и на iPhone.

1. На iPhone откройте **Настройки → ваше имя → iCloud** и включите синхронизацию календаря iCloud. Убедитесь, что нужные события сохранены в календарях iCloud.
2. Войдите на [account.apple.com](https://account.apple.com/). Для аккаунта должна быть включена двухфакторная аутентификация.
3. В разделе **«Вход и безопасность → Пароли приложений»** создайте отдельный пароль для TimeLife. Подробнее — в [инструкции Apple](https://support.apple.com/ru-ru/102654).
4. В TimeLife откройте **Настройки → iCloud**, укажите адрес аккаунта Apple и созданный пароль приложения, затем нажмите **«Подключить iCloud»**. Обычный пароль аккаунта Apple вводить не нужно.
5. Дождитесь загрузки календарей и отметьте нужные в левом меню.

Чтобы события появлялись на обоих устройствах, создавайте их в календарях iCloud. События календаря **«На компьютере»** остаются локальными. Календари Google и Exchange, добавленные на iPhone, через iCloud не синхронизируются.

Синхронизация выполняется через интернет, по умолчанию каждые 5 минут и после изменений в TimeLife. Если одно событие изменено на обоих устройствах, приложение предложит выбрать версию для сохранения.
