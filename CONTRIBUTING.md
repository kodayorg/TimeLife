# Contributing to TimeLife

Maintainer, reviewer and release approver: Koda Yorg (kodayorg@gmail.com).

Use a dedicated branch, run `node --test tests/*.test.cjs`, and include a description of changes and validation. Reviews are required before integrating external contributions. Do not commit user calendars, credentials, private keys, logs, QA profiles or installer caches. Use MFA for repository and signing accounts. Keep dependency notices and MPL source distribution up to date.

Public releases require maintainer review, the configured signing service approval, timestamped valid signatures and a passing public-release check. Unsigned preview installers must retain their Preview name.
